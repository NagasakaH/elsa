1. **基本情報の記入**: セクション1-2で基本的な情報とアクティビティ一覧を記入
2. **個別設計の詳細化**: セクション3で各アクティビティの詳細設計を記述
3. **実装仕様の確定**: セクション4-6で技術的な実装仕様を明確化
4. **テスト・品質保証**: セクション7-8でテスト戦略と開発ガイドラインを整理
5. **運用・管理**: セクション9-11で運用に必要な情報を記載

**注意**: このテンプレートをClineへの入力として使用する際は、具体的な値や設計内容を記入してから提供してください。特に「個別アクティビティ設計」のセクション3は、実装したいアクティビティごとに詳細に記述することが重要です。
